4. Containerization Implementation Details

4.1 Frontend Dockerfile (frontend/Dockerfile)

Multi-stage build utilizing Node.js 20 for compiling Vite assets and Nginx 1.27 Alpine for high-performance static asset serving and reverse proxying. Passes Hadolint with zero warnings.

# Build stage
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# Production stage
FROM nginx:1.27-alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

4.2 Backend Dockerfile (backend/Dockerfile)

Lightweight production image based on Node.js 20 Alpine. Incorporates security hardening via non-root execution (USER 1000), clean dependency layer caching (npm ci --omit=dev), and Hadolint compliance.

FROM node:20-alpine
WORKDIR /app
ENV NODE_ENV=production \
    PORT=3000
COPY package*.json ./
RUN npm ci --omit=dev && npm cache clean --force
COPY --chown=1000:1000 . .
USER 1000
EXPOSE 3000
CMD ["npm", "start"]

6. CI/CD Pipeline & GitHub Actions Execution

6.1 CD Pipeline Architecture (.github/workflows/cd.yml)

The automated CD workflow executes the following 11 stages upon push to the main branch:

  1. Repository checkout: Clones the submitted code via actions/checkout@v4.
  2. Docker Buildx setup: Initializes Buildx builder using docker/setup-buildx-action@v3.
  3. Docker Hub authentication: Authenticates securely using GitHub Secrets DOCKERHUB_USERNAME and DOCKERHUB_TOKEN.
  4. Backend image build: Builds yuviiii2309/backend:latest and yuviiii2309/backend:${{ github.sha }}.
  5. Backend image publishing: Pushes image tags to Docker Hub.
  6. Frontend image build: Builds yuviiii2309/frontend:latest and yuviiii2309/frontend:${{ github.sha }}.
  7. Frontend image publishing: Pushes image tags to Docker Hub.
  8. Docker Compose image pull: Executes docker compose -f docker-compose.deploy.yml pull to fetch published images.
  9. Application deployment: Spins up the entire four-container stack with docker compose -f docker-compose.deploy.yml up -d.
  10. Backend health verification: Polls http://localhost:3000/health until {"status":"ok"} is received.
  11. Frontend accessibility verification: Verifies HTTP 200 response on http://localhost:8080/ and executes API integration tests.
