3. Implementation Architecture Overview

The application is containerized into a multi-tier microservice architecture adhering to enterprise containerization and security best practices:

  • Frontend Service (React + Vite): Multi-stage Docker build utilizing node:20-alpine for lean production compilation and nginx:1.27-alpine for serving production static assets and reverse-proxying /api/ and /health endpoints to the backend.
  • Backend Service (Node.js + Express): Production Dockerfile built on node:20-alpine. Employs non-root execution (USER node), automated dependency caching (npm install --omit=dev && npm cache clean --force), and zero hardcoded credentials.
  • Database Service (PostgreSQL 16): PostgreSQL container with automated schema initialization via /docker-entrypoint-initdb.d/init.sql and named persistent storage volume postgres_data.
  • Cache Service (Redis 7): Redis in-memory cache for API performance acceleration and rapid query retrieval.
  • Network Isolation: Dedicated bridge network (taskflow-network) enabling seamless inter-service DNS communication.
4. Core Configuration Deliverables

A. Frontend Multi-Stage Dockerfile (frontend/Dockerfile)

# Multi-stage build for React frontend application
# Stage 1: Build the React application
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm install && npm cache clean --force
COPY . .
RUN npm run build

# Stage 2: Serve the production build using Nginx
FROM nginx:1.27-alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

B. Backend Production Dockerfile (backend/Dockerfile)

# Production Dockerfile for Node.js Express backend
FROM node:20-alpine
WORKDIR /app
ENV NODE_ENV=production
ENV PORT=3000
COPY package*.json ./
RUN npm install --omit=dev && npm cache clean --force
COPY --chown=node:node . .
USER node
EXPOSE 3000
CMD ["node", "src/server.js"]
